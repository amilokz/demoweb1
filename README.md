# Royal Home Collection — React Demo

## Quick preview
Open `index.html` directly in Chrome/Edge. It uses React 18 from CDN and contains the complete demo, so it does not show a blank page simply because npm dependencies are not installed.

## Development
For a normal Vite React workflow, rename `vite-index.html` to `index.html`, then run:

```bash
npm install
npm run dev
```

The React source is in `src/main.jsx` and `src/styles.css`.

## Included
- Urdu / English global language switch
- Automatic RTL/LTR layout
- Global font selector: Clean, Nastaliq, Modern, Elegant
- Dark glassmorphism UI
- Floating/animated imagery
- Category filtering
- Product detail modal
- WhatsApp ordering
- Retail + wholesale
- Advance payment
- All Pakistan delivery
